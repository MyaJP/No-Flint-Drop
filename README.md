# No Flint Drop

A data pack: **gravel never drops flint**. Craft **1 gravel into 1 flint** instead.

- Minecraft 1.13 – 26.3 in one file (pack overlays for the newer recipe and loot table formats)

**Install:** put the zip in your world's `datapacks` folder, then run `/reload`.

`pack/` holds the data pack and `VERSION` its version. The Publish workflow zips it and uploads it to Modrinth and CurseForge.
